## Notes

- **Wikimedia Commons license checks must be done per-file**, not per-category. A category page (e.g. "Buster Boyd Bridge") can contain files under different licenses.
- **CC0** = no attribution legally required. Credit anyway as good practice.
- **CC-BY / CC-BY-SA** = attribution required. Use format: `Photo: [Author name], [License abbreviation], via Wikimedia Commons` and link back to the file page.
- If a license can't be confirmed on the file page itself, do not use the image — move to the next candidate.
- If an image is later swapped out, keep its row and mark it `(removed, replaced by ___)` rather than deleting the row, so there's a full history.
